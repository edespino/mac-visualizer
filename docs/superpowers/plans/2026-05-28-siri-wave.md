# Siri-Wave Visualizer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an 8th visualizer style `.siri` — a stack of 1–6 centered overlapping smooth waves, each bound to an equal-band group of the spectrum. Amplitudes track per-wave EMA; phases are modulated by a small inline 1-D value-noise function for organic motion. Filled colored triangles, no rendering-pipeline changes.

**Architecture:** New `final class SiriWaveVisualizer: Visualizer` (stateful — carries per-wave amplitudes, frequencies, noise seeds, and a `phaseTime` accumulator). Wave count is driven by a new top-level `siriWaveCount: Int` setting on `VisualizerSettings` (default 3). Waves are sampled at 256 x-points across `[-1, +1]` and emitted as filled ribbons between the curve and y=0. Colors come from the active palette gradient. The existing bloom does the glow.

**Tech Stack:** Swift 5.10, XCTest, simd, QuartzCore. No new shaders, no new pipeline states.

**Builds on:** `main` after plan-10 (demo mode) merged. Spec: `docs/superpowers/specs/2026-05-28-siri-wave-design.md`.

**Scope boundary:** No alpha/additive blending, no full-screen layout, no per-wave color customization beyond the palette gradient, no new visualizer protocol changes.

```swift
import simd
import QuartzCore

/// 8th visualizer style: centered overlapping smooth waves (Siri-assistant
/// inspired). Each wave is bound to an equal-band group of the spectrum; its
/// amplitude tracks that group's energy (smoothed via EMA), its phase wanders
/// via a small inline 1-D value-noise function so motion feels organic.
/// Stateful — the renderer caches one instance across frames.
public final class SiriWaveVisualizer: Visualizer {
    private struct Wave {
        var amplitude: Float        // smoothed band-group mean
        let baseFreq1: Float        // sine 1 base frequency in radians per NDC unit
        let baseFreq2: Float        // sine 2 base frequency
        let noiseSeed1: UInt64
        let noiseSeed2: UInt64
    }

    private var waves: [Wave] = []
    private var lastWaveCount: Int = 0
    private var lastTimestamp: CFTimeInterval = -1
    private var phaseTime: Double = 0
    private var rng: SeededRNG

    // Tunables
    private let sampleCount = 256
    private let smoothing: Float = 0.18         // per-frame EMA weight (~ several frames to converge)
    private let gainMul: Float = 1.6            // group-mean → amplitude headroom
    private let heightCap: Float = 0.40         // max wave amplitude in NDC
    private let noiseSpeed: Double = 0.6        // phaseTime advance per second
    private let baseFreqMin: Float = 4.0        // radians across NDC width
    private let baseFreqSpread: Float = 4.0     // additional radians per wave + per sine

    public init(seed: UInt64 = 0xC0DE5) {
        self.rng = SeededRNG(seed: seed)
    }

    public func makeVertices(frame: AudioFrame, settings: VisualizerSettings, aspect: Float) -> [BarVertex] {
        let n = max(1, min(6, settings.siriWaveCount))
        if n != lastWaveCount { rebuild(n: n) }

        // dt advance for phase noise.
        let dt: CFTimeInterval
        if lastTimestamp < 0 {
            dt = 0
        } else {
            dt = max(0, frame.timestamp - lastTimestamp)
        }
        lastTimestamp = frame.timestamp
        phaseTime += min(dt, 0.1) * noiseSpeed

        // Per-wave amplitude EMA from equal-band-group means.
        let bands = frame.bands
        for i in 0..<n {
            let target = groupMean(bands: bands, group: i, total: n) * gainMul
            waves[i].amplitude += smoothing * (target - waves[i].amplitude)
        }

        // Pre-sample y-values per wave for all x-positions.
        var ysPerWave = [[Float]](repeating: [], count: n)
        for i in 0..<n {
            let phi1 = Float(value1D(phaseTime, seed: waves[i].noiseSeed1)) * 2 * .pi
            let phi2 = Float(value1D(phaseTime, seed: waves[i].noiseSeed2)) * 2 * .pi
            var ys = [Float](repeating: 0, count: sampleCount)
            for j in 0..<sampleCount {
                let x = Float(j) / Float(sampleCount - 1) * 2 - 1
                let s1 = sinf(x * waves[i].baseFreq1 + phi1)
                let s2 = sinf(x * waves[i].baseFreq2 + phi2)
                ys[j] = (s1 + s2) * 0.5 * waves[i].amplitude * heightCap
            }
            ysPerWave[i] = ys
        }

        // Resolve palette.
        let palette = ColorPalette.preset(named: settings.paletteName)
            ?? ColorPalette.preset(named: "classic")!

        // Emit filled ribbons (two triangles per x-segment between curve and y=0).
        var verts: [BarVertex] = []
        verts.reserveCapacity(n * (sampleCount - 1) * 6)
        for i in 0..<n {
            let colorPos: Float = n == 1 ? 0.5 : Float(i) / Float(n - 1)
            let c = palette.sample(at: colorPos)
            let color = SIMD4<Float>(c.r, c.g, c.b, 1)
            let ys = ysPerWave[i]
            for j in 0..<(sampleCount - 1) {
                let x0 = Float(j) / Float(sampleCount - 1) * 2 - 1
                let x1 = Float(j + 1) / Float(sampleCount - 1) * 2 - 1
                let y0 = ys[j]
                let y1 = ys[j + 1]
                let p00 = SIMD4<Float>(x0, 0, 0, 0)
                let p10 = SIMD4<Float>(x1, 0, 0, 0)
                let p0y = SIMD4<Float>(x0, y0, 0, 0)
                let p1y = SIMD4<Float>(x1, y1, 0, 0)
                verts.append(BarVertex(position: p00, color: color))
                verts.append(BarVertex(position: p10, color: color))
                verts.append(BarVertex(position: p0y, color: color))
                verts.append(BarVertex(position: p10, color: color))
                verts.append(BarVertex(position: p1y, color: color))
                verts.append(BarVertex(position: p0y, color: color))
            }
        }
        return verts
    }

    private func rebuild(n: Int) {
        lastWaveCount = n
        waves = (0..<n).map { i in
            let f1 = baseFreqMin + Float(i) * 1.3 + Float(rng.nextUnit()) * baseFreqSpread * 0.25
            let f2 = baseFreqMin + Float(i) * 1.6 + Float(rng.nextUnit()) * baseFreqSpread * 0.25 + 1.7
            let s1 = rng.nextU64()
            let s2 = rng.nextU64()
            return Wave(amplitude: 0, baseFreq1: f1, baseFreq2: f2,
                        noiseSeed1: s1, noiseSeed2: s2)
        }
    }

    private func groupMean(bands: [Float], group: Int, total: Int) -> Float {
        if bands.isEmpty { return 0 }
        let n = bands.count
        let lo = (group * n) / total
        let hi = ((group + 1) * n) / total
        if hi <= lo { return bands[min(lo, n - 1)] }
        var sum: Float = 0
        for k in lo..<hi { sum += bands[k] }
        return sum / Float(hi - lo)
    }
}

// MARK: - 1-D value noise

/// Smooth deterministic 1-D value noise. Hash integer steps + smoothstep
/// interpolate. Output in [0, 1].
private func value1D(_ x: Double, seed: UInt64) -> Float {
    let xi = floor(x)
    let xf = Float(x - xi)
    let i = UInt64(bitPattern: Int64(xi))
    let a = hashToUnit(i, seed: seed)
    let b = hashToUnit(i &+ 1, seed: seed)
    let u = xf * xf * (3 - 2 * xf)
    return a * (1 - u) + b * u
}

private func hashToUnit(_ x: UInt64, seed: UInt64) -> Float {
    var h = x &+ (seed &* 0x9E3779B97F4A7C15)
    h ^= h >> 33
    h = h &* 0xff51afd7ed558ccd
    h ^= h >> 33
    h = h &* 0xc4ceb9fe1a85ec53
    h ^= h >> 33
    return Float(h >> 40) / Float(1 << 24)
}

// MARK: - Seeded RNG (xorshift64), duplicated from other particle visualizers per spec.

private struct SeededRNG {
    private var state: UInt64
    init(seed: UInt64) { state = seed == 0 ? 0x9E3779B97F4A7C15 : seed }
    mutating func nextU64() -> UInt64 {
        state ^= state << 13
        state ^= state >> 7
        state ^= state << 17
        return state
    }
    mutating func nextUnit() -> Float {
        return Float(nextU64() >> 40) / Float(1 << 24)
    }
}
```

## Notes on implementation choices

- **No rendering-pipeline changes.** The bloom does the visual glue for overlapping waves. If the overlap looks muddy in practice (Task 4 live verify), we can add an additive-blend pipeline in a follow-up plan.
- **Top-level `siriWaveCount` (not in `StyleProfile`)** mirrors the four `fireworks*` tunables — single-style settings that only apply when their style is active live at the top level instead of being duplicated across every profile.
- **Inline 1-D value-noise** (no external library) — ~25 lines, deterministic via a 64-bit hash, smoothstep interpolation. Same place visual-style code has historically lived: inline private helpers in the visualizer file.
- **Two-sine sum** for wave shape (instead of one sine) is the VisuAc-style interference pattern — the slow beat between `f1` and `f2` is what makes the wave feel organic rather than mechanical.
- **`SeededRNG` is duplicated again** (4th place in the codebase now: Fireworks, Fountain, Particles, Siri). Consistent with the prior decision: small `private struct`, three lines, not worth promoting to a shared file yet. If it becomes a 5th or 6th, factor out.
- **Stub visualizer in Task 1** keeps Task 1 atomically green (factory test for `.siri` requires a class to exist). Task 2 replaces it with the real implementation in one commit — the in-between state is buildable but produces no vertices.
